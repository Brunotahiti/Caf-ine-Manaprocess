# Caféine — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une app macOS de barre de menus qui garde un MacBook actif capot fermé via `pmset disablesleep`, avec garde-fous batterie, thermique et minuteur.

**Architecture:** Un paquet Swift à trois cibles. `CafeineCore` contient toute la logique, sans interface ni IOKit, et se teste seule. `Cafeine` est l'exécutable SwiftUI (`MenuBarExtra`) qui branche IOKit et `Process` sur le cœur. `build.sh` assemble le `.app`.

**Tech Stack:** Swift 5.9+, SwiftPM, SwiftUI, IOKit, ServiceManagement, XCTest. Aucune dépendance externe.

**Spec:** `docs/superpowers/specs/2026-11-12-cafeine-design.md`

## Global Constraints

- macOS 13 minimum (`platforms: [.macOS(.v13)]`, `LSMinimumSystemVersion` 13.0).
- Aucune dépendance externe.
- Tous les textes visibles sont en français, avec les libellés exacts de la spec (section 3).
- Commandes système toujours par chemin absolu : `/usr/bin/pmset`, `/usr/bin/sudo`, `/usr/bin/osascript`, `/usr/sbin/visudo`, `/usr/bin/install`.
- Fichier sudoers : `/etc/sudoers.d/cafeine`, `root:wheel`, mode `0440`.
- Identifiant de bundle `com.cafeine.app`, `LSUIElement` à `true`, nom du bundle `Caféine.app`, exécutable `Cafeine`.
- Messages de commit en français, terminés par les lignes d'attribution de la session.
- `Package.swift` ne déclare la cible `Cafeine` que sous `#if os(macOS)`, pour que `swift test` fonctionne aussi sous Linux sur `CafeineCore`.

### Écarts de nommage par rapport à la spec

- `Settings` devient `Preferences` et `duration` est de type `AwakeDuration` : `Settings` et `Duration` entrent en conflit avec SwiftUI et la bibliothèque standard.
- `Decision` gagne un cas `.inactive` (Caféine non activée).
- `Policy.decide` reçoit `acOnly` et `batteryThreshold` en valeurs simples plutôt que l'objet de préférences.
- La règle sudoers est écrite par le script root lui-même dans un fichier `mktemp`, et non par Caféine dans un fichier temporaire de l'utilisateur : pas de fichier modifiable entre la validation et la copie.
- `Status` et `StatusText` (texte de la ligne d'état) sont ajoutés à `CafeineCore` pour être testables.

### Vérification

L'environnement de cette session est sous Linux, sans Swift. Avant la tâche 1, tenter d'installer une chaîne Swift pour Linux ; si elle s'installe, chaque étape « Run » des tâches 1 à 4 s'exécute ici. Sinon, le code est écrit sans être exécuté, et le rapport final le dit pour chaque tâche. Les tâches 5 et 6 ne se vérifient que sur macOS.

## Review Focus

1. `pmset -g` sans ligne `SleepDisabled` (certains Mac) : `isSleepDisabled()` renvoie `false` au lieu d'échouer. Test en tâche 4.
2. Batterie à 5 % mais branchée sur secteur : Caféine reste active, le seuil ne vaut que sur batterie. Test en tâche 3.
3. Valeur de seuil ou de durée corrompue dans `UserDefaults` : retour à la valeur par défaut, sans plantage. Test en tâche 1.
4. Nom d'utilisateur avec majuscule, point ou espace : refus net avec `SleepError.invalidUserName`, aucune commande lancée. Test en tâche 4.
5. Annulation de la boîte de dialogue d'authentification : `SleepError.authorizationCancelled`, Caféine reste inactive sans message d'erreur alarmant. Test en tâche 4.

```swift
public struct CommandResult: Equatable {
    public var exitCode: Int32; public var stdout: String; public var stderr: String
    public init(exitCode: Int32, stdout: String = "", stderr: String = "")
}
public protocol CommandRunner {
    func run(_ executable: String, _ arguments: [String]) throws -> CommandResult
}
public enum SleepError: Error, Equatable {
    case invalidUserName(String)
    case authorizationCancelled
    case unauthorized              // sudo -n refusé
    case commandFailed(String)     // stderr ou description
    case stateMismatch             // l'état relu diffère de l'état voulu
}
public struct SleepController {
    public init(runner: CommandRunner, userName: String)
    public static func sudoersRule(for userName: String) throws -> String
    public func isSleepDisabled() throws -> Bool
    public func setSleepDisabled(_ disabled: Bool) throws
    public func isAuthorized() -> Bool
    public func installAuthorization() throws
}
```

Commandes exactes :

| Méthode | Exécutable | Arguments |
|---|---|---|
| `isSleepDisabled` | `/usr/bin/pmset` | `["-g"]` |
| `setSleepDisabled(true)` | `/usr/bin/sudo` | `["-n", "/usr/bin/pmset", "-a", "disablesleep", "1"]`, puis relecture par `isSleepDisabled` |
| `isAuthorized` | `/usr/bin/sudo` | `["-n", "-l", "/usr/bin/pmset", "-a", "disablesleep", "1"]` ; vrai si code 0, faux sinon ou si le lancement échoue |
| `installAuthorization` | `/usr/bin/osascript` | `["-e", script]` |

Règle sudoers, pour l'utilisateur `bruno` :

```
bruno ALL=(root) NOPASSWD: /usr/bin/pmset -a disablesleep 0, /usr/bin/pmset -a disablesleep 1
```

Script shell exécuté en root par `installAuthorization` (`<règle>` remplacé par le texte ci-dessus) :

```sh
umask 077; /bin/mkdir -p /private/etc/sudoers.d; T=$(/usr/bin/mktemp /private/etc/cafeine.XXXXXX) || exit 1; /usr/bin/printf '%s\n' '<règle>' > "$T" && /usr/sbin/visudo -cf "$T" && /usr/bin/install -m 0440 -o root -g wheel "$T" /private/etc/sudoers.d/cafeine; S=$?; /bin/rm -f "$T"; exit $S
```

L'argument `script` passé à `osascript` est `do shell script "<script shell>" with administrator privileges`, les `\` et `"` du script shell étant échappés pour AppleScript.

Correspondance des erreurs :

- `setSleepDisabled`, code non nul : `.unauthorized` si stderr contient `password`, sinon `.commandFailed(stderr)`.
- `setSleepDisabled`, état relu différent : `.stateMismatch`.
- `installAuthorization`, code non nul : `.authorizationCancelled` si stderr contient `-128`, sinon `.commandFailed(stderr)`.
- `isSleepDisabled`, code non nul : `.commandFailed(stderr)`.

**Files:**
- Create: `Sources/Cafeine/ProcessCommandRunner.swift`, `Sources/Cafeine/PowerMonitor.swift`, `Sources/Cafeine/AppModel.swift`, `Sources/Cafeine/CafeineApp.swift`

**Interfaces:**
- Consumes: tout `CafeineCore` (tâches 1 à 4).
- Produces:

```swift
struct ProcessCommandRunner: CommandRunner   // Process + deux Pipe, attend la fin

final class PowerMonitor {
    init(onChange: @escaping () -> Void)   // appelé sur la file principale
    func start()                           // source IOPS sur la run loop principale + notification thermique
    func currentPower() -> PowerState
    func currentThermal() -> ThermalLevel
}

@MainActor final class AppModel: ObservableObject {
    @Published private(set) var status: Status
    @Published var acOnly: Bool              // écrit dans Preferences, puis evaluate()
    @Published var batteryThreshold: Int     // idem
    @Published var duration: AwakeDuration   // idem ; si activé, recalcule endDate depuis maintenant
    @Published var launchAtLogin: Bool       // SMAppService.mainApp register/unregister
    var isEnabled: Bool { get }
    func start()      // remise à 0 si SleepDisabled vaut 1, démarre PowerMonitor et un Timer de 30 s
    func toggle()     // active ou désactive
    func evaluate()
    func shutdown()   // setSleepDisabled(false), erreurs ignorées
}
```

Comportement de `AppModel` :

- `toggle()` vers actif : si `!isAuthorized()`, appeler `installAuthorization()` ; `.authorizationCancelled` laisse le statut `.inactive`, toute autre erreur donne `.error(...)`. Puis `enabled = true`, `endDate = duration.endDate(from: Date())`, `evaluate()`.
- `toggle()` vers inactif : `enabled = false`, `endDate = nil`, veille rétablie, statut `.inactive`.
- `evaluate()` appelle `Policy.decide` puis applique :

| Décision | Veille désactivée | `enabled` | Statut |
|---|---|---|---|
| `.inactive` | inchangé | faux | inchangé (garde le dernier `.stopped` ou `.error`) |
| `.stayAwake` | oui | vrai | `.active(until: endDate)` |
| `.pause(r)` | non | vrai | `.paused(r)` |
| `.stop(r)` | non | faux, `endDate = nil` | `.stopped(r)` |

- `setSleepDisabled` n'est appelé que si l'état voulu diffère du dernier état appliqué.
- Erreur de `setSleepDisabled` : `enabled = false`, tentative de remise à 0, statut `.error("Autorisation manquante")` pour `.unauthorized`, `.error("Erreur : impossible de modifier la veille")` sinon.
- `launchAtLogin` : en cas d'échec, la valeur revient à l'état réel de `SMAppService.mainApp.status` et le statut devient `.error("Lancement au démarrage indisponible")`.

`PowerMonitor.currentPower()` : `onAC` vrai si `IOPSCopyPowerSourcesInfo` indique `kIOPSACPowerValue` ; `batteryPercent` = capacité courante × 100 / capacité maximale de la première source interne, `nil` s'il n'y en a pas. `currentThermal()` traduit `ProcessInfo.processInfo.thermalState`.

Menu (`MenuBarExtra`, style `.menu`), dans cet ordre, libellés exacts :

1. Texte désactivé : `StatusText.text(for: status)`
2. Séparateur
3. Bouton `Activer` ou `Désactiver`
4. Sélecteur `Durée` : les quatre `AwakeDuration.label`
5. Case `Sur secteur uniquement`
6. Sélecteur `Seuil de batterie` : `10 %`, `20 %`, `30 %`
7. Séparateur
8. Case `Lancer au démarrage`
9. Bouton `Quitter` : `NSApplication.shared.terminate(nil)`

Icône : symbole SF `cup.and.saucer.fill` si `status.isAwake`, sinon `cup.and.saucer`. Un `NSApplicationDelegate` (via `@NSApplicationDelegateAdaptor`) appelle `shutdown()` dans `applicationWillTerminate`.
